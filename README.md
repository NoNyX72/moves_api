# Каталог фильмов API (moves_api)

## Краткое описание проекта
REST API сервис для управления каталогом фильмов. Проект позволяет добавлять новые фильмы, просматривать их список, а также фильтровать и сортировать данные.

## Основные возможности приложения
- Просмотр списка всех фильмов с возможностью пагинации (limit, offset).
- Получение детальной информации о фильме по ID.
- Добавление новых фильмов в базу данных.
- Полное обновление (PUT) и частичное обновление (PATCH) данных фильма.
- Фильтрация по году выпуска и минимальному рейтингу.
- Сортировка фильмов (по умолчанию по убыванию рейтинга).

## Технологический стек
- Язык: Python 3.13
- Фреймворк: FastAPI
- Сервер: Uvicorn
- База данных: SQLite (файл movie.db)
- ORM: SQLAlchemy (файл database.py)
- Миграции: Alembic (настройки в alembic.ini)

2. Создание и активация виртуального окружения:
python -m venv venv

3. Установка зависимостей:

## Основные эндпоинты
- GET /movies/ — Получить список фильмов (с поддержкой пагинации, фильтрации и сортировки)
- GET /movies/{movie_id} — Получить фильм по ID
- POST /movies/ — Добавить новый фильм
- PUT /movies/{movie_id} — Полностью обновить данные фильма
- PATCH /movies/{movie_id} — Частично обновить данные фильма
- DELETE /movies/{movie_id} — Удалить фильм

## Фильтрация и сортировка
В эндпоинте GET /movies/ реализованы параметры запроса:
- year_min (int) — минимальный год выпуска
- year_max (int) — максимальный год выпуска
- rating_min (float) — минимальный рейтинг
- order_by (str) — поле для сортировки (по умолчанию "-rating", то есть по убыванию рейтинга)
- limit (int) — количество записей (по умолчанию 50, максимум 100)
- offset (int) — смещение для пагинации

## Модель данных
Основная сущность — Фильм. Таблица содержит поля:
- id (int, Primary Key) — уникальный идентификатор
- title (str) — название фильма
- description (str) — описание
- year (int) — год выпуска
- rating (float) — рейтинг
- genre (str) — жанр

## Ограничения базы данных
- Поле title обязательно для заполнения (NOT NULL).
- Поле year имеет ограничение на положительные значения.
- Поле rating ограничено диапазоном (например, от 0 до 10).
