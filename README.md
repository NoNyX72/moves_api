# Каталог фильмов API (moves_api)

## Краткое описание проекта
REST API сервис для управления каталогом фильмов. Проект позволяет добавлять новые фильмы, просматривать их список, а также фильтровать и сортировать данные.

## Основные возможности приложения
- Просмотр списка всех фильмов.
- Получение детальной информации о фильме по ID.
- Добавление новых фильмов в базу данных.
- Фильтрация и сортировка фильмов.

## Технологический стек
- Язык: Python 3.13
- Фреймворк: FastAPI
- Сервер: Uvicorn
- База данных: SQLite (файл movie.db)
- ORM: SQLAlchemy (файл database.py)
- Миграции: Alembic (настройки в alembic.ini)

## Быстрый старт

1. Клонирование репозитория:
git clone [ссылка на ваш репозиторий]
cd moves_api

2. Создание и активация виртуального окружения:
python -m venv venv
venv\Scripts\activate

3. Установка зависимостей:
pip install -r requirements.txt

4. Применение миграций:
alembic upgrade head

5. Запуск приложения через uvicorn:
uvicorn src.main:app --reload

## Основные эндпоинты
- GET /movies — Получить список фильмов
- GET /movies/{id} — Получить фильм по ID
- POST /movies — Добавить новый фильм
- PUT /movies/{id} — Обновить данные фильма
- DELETE /movies/{id} — Удалить фильм

## Фильтрация и сортировка
В эндпоинте GET /movies реализованы параметры запроса для фильтрации (по жанру или году) и сортировки (по рейтингу или дате).

## Модель данных
Основная сущность — Фильм. Таблица содержит поля:
- id (int, Primary Key) — уникальный идентификатор
- title (str) — название фильма
- description (str) — описание
- year (int) — год выпуска
- rating (float) — рейтинг
- genre (str) — жанр

## Ограничения базы данных
- Поле title обязательно для заполнения (NOT NULL).
- Поле year имеет ограничение на положительные значения.
- Поле rating ограничено диапазоном (например, от 0 до 10).
